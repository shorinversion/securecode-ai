Репозиторий · Отчёт о проекте · Результаты экспериментов

Задача

Разработать ассистента, который анализирует локальный репозиторий, объясняет найденные уязвимости и предлагает исправления. В работе исследуется совместное применение статического анализа и языковой модели для Python, JavaScript, TypeScript и Go.

Устройство приложения

Инструменты анализа извлекают сведения о коде, секретах и зависимостях. Языковая модель выполняет поиск потенциальных уязвимостей. Аудитор сопоставляет находки с доказательствами, Архитектор готовит предложение исправления. Результаты сохраняются в отчёте с указанием файла, строк и класса CWE.

Приложение включает командный интерфейс, серверный API и рабочий процесс для CI. Патчи проверяются в отдельной рабочей копии. Исходный репозиторий сохраняется.

Демонстрация

Продолжительность: 4 минуты 12 секунд. В видео представлены результаты демонстрационных запусков и экспериментов. Голос синтезирован.

Эксперименты

Для сравнения использованы 600 примеров CVEfixes: по 200 для Python, JavaScript/TypeScript и Go. Уязвимые и исправленные версии объединены в пары. Связанные примеры находятся в одной части выборки.

DeepSeek проверен в двух режимах, каждый с тремя повторениями на всём корпусе. Статический анализатор Semgrep использован как базовый метод сравнения. В отложенной выборке полнота составила 27,8% для производной гибридной конфигурации и 32,5% для Semgrep.

В исходном прогоне собственного сканера завершились 347 из 600 случаев. Для 253 случаев сохранён статус ошибки. Эти случаи включены в расчёт доли завершённых проверок. Подробные таблицы, методика расчёта и границы применимости результатов приведены в отчёте об экспериментах.

Результаты локальной демонстрации

Квантованная модель Qwen 2.5 Coder 7B, запущенная через Ollama, обнаружила SQL-инъекцию CWE-89 в демонстрационном файле. Детерминированное правило указало ту же строку. В этом запуске пригодное исправление получено не было; проверки применимости патча и безопасности после исправления остались невыполненными.

Установка зависимостей и демонстрации повторены в чистом каталоге. Продуктовый набор из 140 тестов прошёл. Полная проверка качества текущего дерева содержит нерешённые замечания. Обобщённое превосходство над Semgrep результатами экспериментов не установлено.

Воспроизведение

uv sync --locked --group quality
uv run python -I demo/mvp_cwe89_demo.py --output tmp/demo
uv run python -I demo/p917_real_local_demo.py \
  --repository demo/fixtures/real-local-cwe89 --output tmp/local-demo

Для локального модельного запуска необходимы Ollama и Qwen 2.5 Coder 7B Q4_K_M. Настройки, зависимости и команды приведены в README. Учебный notebook и ссылки на датасет находятся в репозитории.

Развёртывание

Материалы проекта размещены на Cloud.ru. Серверный API запущен в отдельном Docker-контейнере; проверка готовности проходит. Подключение публичного интерфейса аудита к DeepSeek находится в работе.
