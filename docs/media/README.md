# Видеодемонстрация

`securecode-demo.mp4`: 4 минуты 12 секунд, русский язык. Опубликованная версия озвучена OpenAI gpt-4o-mini-tts (marin). Её сценарий сохранён в `narration.openai.ru.txt`.

Видео представляет сохранённые результаты запусков. Запись нового сквозного запуска в него не входит.

`narration.ru.txt` содержит обновлённый сценарий для озвучки голосом владельца через ElevenLabs. Генерация пока не выполнена: API вернул `missing_permissions`, у ключа отсутствует право `text_to_speech`. Опубликованное видео ещё не заменено.

В сервис озвучки передаётся только сценарий. Исходники проекта и ключи в текст не включены.
