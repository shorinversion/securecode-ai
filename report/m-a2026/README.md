# M-A2026 delivery bundle / Комплект сдачи M-A2026

## English

This directory contains a reproducible academic snapshot of SecureCode AI. The files are generated by `scripts/build_m_a2026_submission.py` from repository evidence and recorded experiment results.

- `report.md` is the searchable report with methods, measurements, limitations, and evidence hashes.
- `report.html` is a browser-readable copy of the report.
- `report.pdf` is a printable summary and evidence inventory.
- `delivery-manifest.json` records the snapshot identity and SHA-256 hashes for every delivered file and evidence item.
- `quality-receipt.json` binds the recorded quality result to the exact repository subject.
- `clean-replay.md` gives commands for rebuilding and validating the bundle.

The bundle is intentionally marked `NOT_READY`. It documents an academic prototype and does not claim G7, G9, v1.0, project completion, production readiness, or release readiness. Read the limitations before interpreting the benchmark or demo results.

## Русский

В каталоге находится воспроизводимый учебный снимок SecureCode AI. Файлы создаются скриптом `scripts/build_m_a2026_submission.py` на основе свидетельств из репозитория и сохранённых результатов экспериментов.

- `report.md` содержит описание метода, измерения, ограничения и хеши свидетельств.
- `report.html` открывает отчёт в браузере.
- `report.pdf` предназначен для печати и содержит краткие результаты и список свидетельств.
- `delivery-manifest.json` фиксирует идентичность снимка и SHA-256 каждого файла и свидетельства.
- `quality-receipt.json` связывает результат проверок с точным состоянием исходного репозитория.
- `clean-replay.md` содержит команды для повторной сборки и проверки комплекта.

Статус комплекта намеренно установлен в `NOT_READY`. Это учебный прототип; комплект не заявляет прохождение G7 или G9, выпуск v1.0, завершение проекта, готовность к эксплуатации или готовность к релизу. Перед интерпретацией демонстрации и бенчмарка прочитайте ограничения.
